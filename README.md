# 🎟️ Try-n-Save

## 📖 Sinopsis
**Try-n-Save** es la maqueta de una aplicación web cuyo objetivo es permitir que un cliente canjee un **voucher** entregado al momento de la compra.  

El flujo de uso es el siguiente:
1. El cliente ingresa su **número de documento** para identificarse.  
2. Si es la primera vez que accede, debe **registrarse** completando sus datos personales.  
3. Una vez registrado, podrá **elegir un premio** entre las opciones disponibles.  
4. Finalmente, deberá **ingresar el código del voucher** correspondiente y… ¡el premio será suyo! 🎁  

---

## ⚠️ Aclaraciones
- No se puede canjear un premio sin estar registrado.  
- Un código de voucher solo puede utilizarse **una vez**.  
- Un cliente puede canjear **varios premios**, siempre que tenga diferentes vouchers (uno por compra).  
- Actualmente, solo **un voucher ha sido canjeado**.
